# Modèle de réduction de bruit (voix)

`rnnoise-speech.rnnn` est le modèle « somnolent-hogwash » (2018-09-01) du dépôt
https://github.com/GregorR/rnnoise-models, choisi pour la catégorie
« parole / bruit d'enregistrement ». Il est lu par le filtre `arnndn` de FFmpeg
pour l'amélioration des voix off enregistrées dans Ar cut.

Droits : l'auteur indique dans le README du dépôt qu'en dehors du dossier tools/
et du README, « none of this work is creative and thus none of it is subject to
copyright ». Le modèle est donc redistribuable librement.
